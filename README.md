# Simon Says 🚨
## version 1.0 | authored on March 1st, 2026
This application entertains you in repeating sequences at increasing speeds.

### Installation
#### Windows x64
Locate & download the Windows x64 Edition .zip under "Releases" on Github.com. Unzip it & put the folder where you feel comfortable; press the application's .exe; enjoy the game.

### Development Note
2 developers programmed this application in 1 week. I \(Jacob Groneman\) pair-programmed the game. There is nothing spectacular to this take on Simon, but its development gave us practice with multi-threading & signal-slot model-view-controller workflows in Qt.

Thank you for checking out the application.
